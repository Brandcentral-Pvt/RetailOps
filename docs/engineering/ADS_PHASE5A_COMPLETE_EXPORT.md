# Phase 5A: complete stored-report workbook

Depends on the Phase 4 layout hotfix PR #302. The existing permission-gated canonical-export route now uses a complete streaming workbook built from one authorized serializable snapshot. Normal report queries retain their original lightweight column projection and pagination. The export materializes all 63 contract fields and lineage only for its own snapshot, with stable keyset pages of 1,000 raw rows and 250 entities. Current and equal-length previous windows are included. No other seller's facts, inferred zeros or FX conversion. Catalog filters are identical to canonical report scope. Normalized stored source values are not original CSV bytes; first-import source SHA, row number and import metadata are included, including unchanged historical records.

Workbook: Report Scope, Summary (all 24 additive metrics and 12 compatible ratios, comparison and coverage), Entity Comparisons (all matching groups with exact current/prior/delta and status), Entity Coverage (populated/paired counts and observed/matched ratios), History (all selected buckets), Aligned Trends (equal-length paired dates), Daily Source (all original 63 headers in contract order, then owner/context and lineage), Data Dictionary. Raw numeric fields preserve original scale, including source fractional ratios; recomputed ratio cells use native percentage format, count cells integer, money 2 decimals, percentage-point changes explicit. Values beyond 15 significant digits stored as text; never round backend financial values or execute formula-like text. Unknown numeric cells are blank; actual zero stays numeric. Frozen headers and identity fields, filter ranges, styled headers and usable column widths. Raw row counts, 24 exact additive sums and non-null counts reconcile against the same snapshot. Verify XLSX ZIP/XML and all sheet row counts after releasing the SQL transaction and before any bytes are sent. Private temporary files only; clean up on failure/download. Two active exports per API process including downloads.

First-increment synchronous safety limits: 250,000 combined daily records and 25,000 entities, 170-second generation/verification deadline, explicit 422 for oversized requests, no silent truncation. Actual limits depend on proxy, SQL, disk and deployment resources. Phase 5B will add durable export jobs/Download Center, large-report partitioning, complete portfolio/opportunity/reconciliation sheets and seller-wide budget exports with their own cutoff. No migrations in Phase 5A. Production reconciliation, large workbook performance, and actual Excel desktop opening must be verified after deployment.
